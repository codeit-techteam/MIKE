# Mike

Personal AI memory assistant marketing site for [michaelross.ai](https://michaelross.ai/).

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger via `@gsap/react` `useGSAP()`

## Develop

```bash
npm install
npm run dev
```

## Quality

```bash
npm run lint
npm run typecheck
npm run build
```
